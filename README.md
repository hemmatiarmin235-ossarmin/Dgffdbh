# ARMIN DECK

لانچر گیمینگ بومی اندروید با Java، حداقل Android 8.0 (API 26)، شناسه `com.armin.deck`.

## امکانات نسخه اولیه
- رابط افقی تیره با تأکید سبز نئونی
- فهرست برنامه‌های قابل اجرا و آیکون آن‌ها
- جست‌وجو بر اساس نام یا شناسه بسته
- اجرای برنامه با لمس
- پشتیبانی پایه از کلیدهای جهت‌دار، Enter، Space و دکمه A کنترلر
- بیلد ابری APK با GitHub Actions

## ساخت APK با گوشی و GitHub
1. فایل ZIP پروژه را استخراج کنید یا فایل‌های آن را در مخزن GitHub قرار دهید.
2. نام شاخه اصلی را `main` یا `master` بگذارید.
3. در مخزن به تب **Actions** بروید و در صورت درخواست، workflowها را فعال کنید.
4. workflow با هر push به شاخه `main`/`master` اجرا می‌شود. اجرای دستی: **Actions → Build ARMIN DECK APK → Run workflow**.
5. پس از سبز شدن اجرای workflow، پایین صفحه جزئیات اجرا، بخش **Artifacts** را باز کنید و `armin-deck-debug-apk` را دانلود کنید.
6. ZIP مربوط به Artifact را در گوشی استخراج کنید. فایل `app-debug.apk` را باز کنید و اگر اندروید خواست، اجازه نصب از همین منبع را در تنظیمات بدهید.

## نکات
- این APK نسخه debug است و برای نصب شخصی مناسب است؛ برای انتشار عمومی باید نسخه release و امضای امن پیکربندی شود.
- Android 11 به بعد دیدن برنامه‌های دیگر را محدود می‌کند؛ بخش `<queries>` فقط برنامه‌هایی را قابل مشاهده می‌کند که Activity لانچر دارند.
- نسخه اولیه صفحه اصلی را افقی می‌کند تا حس کنسولی داشته باشد.
- کنترلرها بسته به مدل و نگاشت کلیدهای Android ممکن است کلیدهای متفاوتی گزارش کنند.
- این برنامه سیستم‌عامل Steam Deck یا بازی‌های PC را اجرا نمی‌کند؛ برنامه‌های اندرویدی نصب‌شده را باز می‌کند.
- برای تبدیل آن به لانچر پیش‌فرض سیستم، باید نقش Home و رفتار بازگشت/صفحه اصلی جداگانه اضافه و آزمایش شود؛ نسخه فعلی لانچر قابل اجرا از آیکون برنامه است.
